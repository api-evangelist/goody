Goody (ongoody.com) is a business and personal gifting platform that lets senders deliver physical products and gift cards without needing a recipient's address — the recipient accepts via a shareable gift link and can swap the gift. For developers, Goody exposes a REST Commerce/Automation API (base https://api.ongoody.com, with a separate sandbox at api.sandbox.ongoody.com) to browse a curated product catalog, price and send gift order-batches to one or many recipients, manage contacts and autogift rules, and track order lifecycle. Bearer API-key auth for the REST API, plus an official hosted MCP server (OAuth2 + PKCE) exposing 28 tools so agents can discover, draft, price, and send gifts in natural language. Webhooks (via Svix) cover the full order lifecycle. SOC 2 certified. Backed by Index Ventures.

**Areas:** Company · Retail · Gifting · Gift Cards · E-Commerce · Commerce · Payments · MCP · Webhook · Rewards

## How this profile is made
